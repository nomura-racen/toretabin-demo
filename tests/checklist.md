# とれたら便 確認リスト

src/index.html をダブルクリックで開いて確かめる。
始める前に「最初の状態に戻す」を押しておく。

- [ ] src/index.html をダブルクリックで開くと表紙が出て、「農家として見る」「お客さんとして見る」で画面が切り替わる
- [ ] デモ用の時計が 2026年8月5日 9時 から始まり、「+6時間」「+1日」で進み、「最初に戻す」で 8月5日 9時 に戻る
- [ ] 農家が収穫回（品目・収穫予定日・予約上限・1人あたりの上限）を作ると、農家の一覧とお客さんの一覧の両方に出る
- [ ] お客さんが予約するとき、1人あたりの上限を超える数量は選べない
- [ ] お客さんが予約すると「予約中」になり、この時点では支払いを求められない
- [ ] とうもろこし8月上旬で見込み量90を入れると81箱を割り当てる
- [ ] 振り分けは、確定する前に結果を見られる。確定するまで予約の状態は変わらない
- [ ] 足りないとき、繰り越しで優先の予約が先に、その中と残りは予約日時が古い順に割り当てられる
- [ ] 足りないとき、「そろった分だけ送る」の人は残りを全部割り当てられ、足りない分が次の収穫回へ繰り越される
- [ ] 足りないとき、「全部そろうまで待つ」の人は割り当てられず、全部が次の収穫回へ繰り越される。次の収穫回がなければ「次の回待ち」になり、同じ品目の収穫回を作るとそこへ優先で入る
- [ ] 確定すると、カード登録の人は「支払い済み」、確定後に支払う人は「支払い待ち」になり、余った数が「追加で受け付けられる数」として出る
- [ ] 時計を6時間進めると赤肉メロンの支払い待ちが期限切れになり、補欠に案内が回る
- [ ] 収穫・出荷リストに支払い済みの分だけが、配送と農園受け取りに分かれて出て、印刷できる
- [ ] 画面で変えたことは、ページを開き直しても残り、「最初の状態に戻す」で消える
- [ ] 状態が色だけでなく文字でも分かり、ボタンの高さが44px以上ある。お客さんの画面はスマホの縦向きで崩れない
