# とれたら便 仕様書

## 1. とれたら便とは

直販をしている農家のための、収穫に合わせた予約販売の仕組み。
在庫数を決めずに予約を受け、収穫の3日前に見込み量で振り分け、支払いが済んだ分だけ収穫して届ける。

## 2. ワークショップの項目

| 項目 | 内容 |
|---|---|
| 売る相手 | 直販をしている農家1軒（デモは架空の森野ファーム・北海道東川町） |
| 最初のお客さんの顔 | （要記入） |
| 今どうしているか | 予約を電話やメールで受けてノートに記録／収穫量が読めず在庫数を決められない／振り分けと連絡を手作業／収穫後に払われないと無駄になる |
| 払う人 | 農家 |
| 使う人 | 農家とお客さん |
| 値段の感覚 | 月3,000〜1万円、または予約売上の数％ |
| ラセンから買う理由 | 農家ごとに合わせて直せる／HPとセットで作れる／地元で顔が見える |

## 3. 流れ

1. 農家が収穫回を作る。収穫回には、品目・収穫予定日・予約上限・1人あたりの上限を決める
2. お客さんが予約する。次のものを選ぶ。予約した時点ではお金はかからない
   - 数量
   - 一部しか用意できないときの希望：「そろった分だけ送る」／「全部そろうまで待つ」
   - 受け取り方法：「配送」／「農園で受け取り」
   - 支払い方法：「カード登録」／「確定後に支払う」
3. 収穫予定日の3日前（確定日）に、農家が見込み量を入れる
4. 振り分けて、お客さんに連絡する
5. 支払い
   - カード登録の人：確定と同時に支払い済みになる
   - 確定後に支払う人：期限までに支払う。期限は品目ごとに決まっている
6. 期限が切れた分は、補欠（繰り越しの人）に順番に案内する。案内を受けた人は、案内から12時間以内に受け取るかどうかを決める
7. 収穫日に、支払い済みの数だけ収穫して届ける

## 4. 振り分けのルール

1. 割り当てる数 ＝ 見込み量 × 0.9（小数点以下は切り捨て）
2. 並び順
   - 繰り越しで優先になっている予約が先
   - その中と、残りの予約は、それぞれ予約日時が古い順
3. 予約数をそのまま割り当てられるなら、全部割り当てる
4. 足りないとき
   - 「そろった分だけ送る」の人：残っている数を全部割り当て、足りない分を次の収穫回へ繰り越す
   - 「全部そろうまで待つ」の人：割り当てず、全部を次の収穫回へ繰り越す
5. 次の収穫回がないときは「今回はご用意できませんでした」としてキャンセルにする
6. 余った数は「追加で受け付けられる数」として表示する
7. カードが使えない人は「確定後に支払う」と同じ扱いにする

## 5. 予約の状態

- 予約受付中
- 支払い待ち
- 支払い済み
- 繰り越し
- 期限切れ
- キャンセル
- 発送済み
- 受け取り済み

## 6. 画面

### 表紙
- タイトル
- キャッチコピー
- 「農家として見る」ボタン
- 「お客さんとして見る」ボタン

### 農家の画面
- ホーム：今日やること、収穫回の一覧
- 収穫回の詳細
- 見込み量の入力と振り分け：確定する前に結果を見られる
- 収穫・出荷リスト：配送と農園受け取りを分けて表示する。印刷できる
- お客さんへの連絡の履歴
- 収穫回を作る

### お客さんの画面
- お客さんを選ぶ（デモ用）
- 収穫回の一覧と予約
- 自分の予約：支払う／キャンセル／空きの案内を受け取る・見送る

### デモ用の時計
- 最初は 2026年8月5日 9時
- ボタン：「+6時間」「+1日」「最初に戻す」

## 7. 見た目

- 農家の画面：数字がひと目で分かる
- お客さんの画面：スマホの縦向きが基本。畑から届く便りのような、あたたかい雰囲気
- ボタンの高さは44px以上
- 状態は色だけでなく、文字でも分かるようにする

## 8. 今回は作らないもの

- 実際の決済
- メールやSMSの送信
- 送り状
- ログイン
- 個人情報の扱いのルール
- 特定商取引法の表記
- 複数の農家での利用
- 本番運用

## 9. 決まっていないこと

作る前に決める必要があります。

1. 補欠への案内に12時間以内に答えなかったとき、どうなるか（次の人に回すか、など）
2. 補欠に案内する数（期限切れになった数をまとめて1人に案内するか、その人が足りなかった数だけか）
3. 補欠が「受け取る」を選んだあとの支払い（その場で支払い済みか、新たに期限を設けるか）
4. お客さんが自分でキャンセルできるのは、どの状態のときまでか
5. 「追加で受け付けられる数」に、確定後も新しく予約できるか
6. 「発送済み」「受け取り済み」にするのは誰の操作か（農家が出荷リストで付けるか、など）
7. 確定日の何時に振り分けるか、農家が手で行うか時計で自動か
8. 品目ごとの支払い期限の長さ（確定から何時間か）
