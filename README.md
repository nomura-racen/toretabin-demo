# とれたら便（デモ）

> とれた分だけ、待っている人へ。

直販をしている農家のための、収穫に合わせた予約販売の仕組みのデモです。
在庫数を決めずに予約を受け付け、収穫の3日前に「今回とれそうな数（見込み量）」を入れると、誰に届けて誰を次の回に回すかを自動で振り分けます。支払いが済んだ分だけ収穫するので、払われなかった分が無駄になりません。

- 作成：野村（ワークショップ「AIだけでつくる 売れるアプリ」の卒業制作・第2案）
- 作り方：Claude Code に日本語で仕様を渡し、1ステップずつ作らせた
- データ：人・農園・メールアドレスはすべて架空（デモの舞台は北海道東川町の「森野ファーム」）

## 開き方

1. このリポジトリをダウンロードする（緑の「Code」→「Download ZIP」を押し、ZIPを展開する）
2. `src/index.html` をダブルクリックして、ブラウザで開く

サーバーやインストールは要りません。画面で変えたこと（予約・確定・時計など）はブラウザに保存されます。いちばん下の「最初の状態に戻す」で消えます。

## デモの見せ場

デモ用の時計は 2026年8月5日 9:00 から始まります。右下（スマホでは下）の「+6時間」「+1日」で進めます。

1. **振り分け**：農家で「とうもろこし 8月上旬」を開き、見込み量に 90 を入れる。数字を変えるたびに、届ける人・次の回に回す人がその場で変わる。「この内容で確定する」で、支払いとお客さんへの連絡まで一度に決まる
2. **払われなかった分を補欠へ**：「+6時間」を押すと、赤肉メロン 8月上旬の支払い待ちが期限切れになり、空いた分が次の回に回っていた人に案内される。三浦 洋平さんでログインして「受け取る」を押す。もう一度「+6時間」を押すと、ほかの人が自動で返事をする（デモ用）
3. **次の回待ち**：農家で「赤肉メロン 8月中旬」に 30 を入れて「確定日に自動で確定する」を押し、「+1日」を7回押す。次の回がないので、足りない分は「次の回待ち」になる。「品目と収穫回」で赤肉メロンの 8月28日 の回を作ると、そこへ優先で入る
4. **追加受付**：最初の状態に戻してから、とうもろこし 8月上旬を見込み量 120 で確定すると、余りが「追加受付中」になる。上野 さくらさんでログインすると、先着順で追加の予約ができる

## できること

- **農家**：今日やること／収穫回の一覧と詳細／見込み量の試し計算と確定（確定日に自動で確定もできる）／受付をやめる・再開する／空いた数の行き先／品目と収穫回を作る／お客さんへの連絡の履歴／連絡の文とお店の紹介の書き換え
- **お客さん**：予約（同じ回の予約は1枚にまとまる）／予約の変更とキャンセル／支払い／空きの案内への返事（受け取る・見送る）／追加受付中の回への予約

くわしい決まりは [docs/spec.md](docs/spec.md) にあります。

## フォルダの中身

```
README.md            このファイル
CLAUDE.md            AI（Claude Code）との約束事
docs/spec.md         仕様書
tests/checklist.md   確認リスト
src/index.html       画面の骨組み（これをダブルクリックで開く）
src/css/style.css    見た目
src/data/data.js     架空データ
src/js/store.js      読み込みと保存
src/js/clock.js      デモ用の時計
src/js/rules.js      決まり（振り分け・支払い期限・補欠への案内・受付・連絡の文）
src/js/farmer.js     農家の画面
src/js/customer.js   お客さんの画面
src/js/app.js        ログイン、画面の切り替え、起動
```

売り方の決まり（割り当てる割合、確定日、案内の返事の期限など）は、`src/js/rules.js` の1か所にまとめています。農家ごとに売り方を変えたいときは、ここだけを直します。
